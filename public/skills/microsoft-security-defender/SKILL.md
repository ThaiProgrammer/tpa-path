# Microsoft Cybersecurity & Zero Trust Specialist Skill

## The Zero Trust Model
1. **Verify Explicitly**: Authenticate and authorize based on all available data points (identity, location, device health, service or workload).
2. **Use Least Privilege Access**: Limit user access with Just-In-Time and Just-Enough-Access (JIT/JEA), risk-based adaptive policies, and data protection.
3. **Assume Breach**: Minimize blast radius and segment access. Verify end-to-end encryption and utilize analytics to gain visibility and threat detection.

## Microsoft Security Solution Architecture
- **Microsoft Entra ID**: Conditional Access policies, Multi-Factor Authentication (MFA), Privileged Identity Management (PIM).
- **Microsoft Defender for Cloud**: Cloud Security Posture Management (CSPM) and Cloud Workload Protection (CWPP).
- **Microsoft Defender XDR**: Unified endpoint, identity, email, and cloud app threat protection.
- **Microsoft Sentinel**: Cloud-native SIEM and SOAR with automated incident response playbooks using Azure Logic Apps.
- **Microsoft Purview**: Data governance, data loss prevention (DLP), sensitive data discovery and classification.
