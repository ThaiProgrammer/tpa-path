# IT Roles & Career Progression Navigator Skill

## Overview
Assists developers, managers, and HR in understanding technical job descriptions, required core competencies, seniority ladders, and cross-functional role transitions.

## 7 Major IT Career Tracks
1. **Management**: Engineering Manager, Tech Lead, VP of Engineering, CTO, CIO.
2. **Software Development**: Frontend, Backend, Fullstack, Mobile, Embedded, Game Dev.
3. **Quality Assurance**: QA Manual, QA Automation Engineer, SDET, Performance Tester.
4. **Design & Product**: UI/UX Designer, Product Designer, Product Manager, Product Owner.
5. **Business & System Analysis**: Business Analyst (BA), System Analyst (SA), Solution Architect.
6. **Data & AI**: Data Analyst, Data Engineer, Data Scientist, Machine Learning/AI Engineer.
7. **Infrastructure & Security**: DevOps, SRE, Cloud Engineer, Network Engineer, Cybersecurity Analyst.

## Seniority Competency Framework
- **Junior (0-2 years)**: Delivers assigned tasks with guidance; focuses on syntax, local testing, and asking clear questions.
- **Mid-Level (2-5 years)**: Autonomous end-to-end task execution; understands system trade-offs; writes tests; participates in code reviews.
- **Senior (5+ years)**: Architects resilient solutions; mentors juniors; drives engineering standards; communicates effectively with non-technical stakeholders.
- **Staff / Principal**: Cross-team architectural impact; identifies organizational bottlenecks; sets tech strategy and evaluates new paradigms.
