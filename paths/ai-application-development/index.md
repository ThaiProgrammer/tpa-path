# AI Application Development Guideline for Developer

รวบรวมพื้นฐานสำหรับนักพัฒนาโปรแกรมที่ต้องการเริ่มต้นสร้าง หรือเพิ่มความสามารถให้แอพตัวเองเป็น AI Application ด้วยเนื้อหาที่มาในรูปแบบของ Roadmap ที่ประกอบไปด้วยคำอธิบายสั้นๆและสามารถที่จะโต้ตอบกับผู้เรียนได้ด้วย เพื่อให้คุณสามารถเรียนรู้ทุกสิ่งที่คุณต้องการได้ในที่เดียวครบเลยครับผม

## หัวข้อการเรียนรู้

### 1. [บทนำและเครื่องมือ AI ฝั่ง Microsoft](/paths/ai-application-development/introduction/introduction)
ทำความเข้าใจภาพรวมและบริการ AI ต่างๆ เช่น Azure AI Services, Azure Machine Learning และ Azure OpenAI

### 2. [การศึกษา AI เบื้องต้น: OpenAI, RAG และ Vector Search](/paths/ai-application-development/rag/rag-vector-search)
เจาะลึกสถาปัตยกรรม Retrieval-Augmented Generation (RAG), การทำ Vector Embeddings, การค้นหาข้อมูลด้วย MongoDB Atlas Vector Search และการพัฒนาแอปด้วย Semantic Kernel C#
