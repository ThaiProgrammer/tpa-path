# 2026 Knowledge Improvement Task Plan

This checklist is structured as phased tasks so you can open one branch per phase and continue incrementally.

## Branch and PR Workflow (from contribution guide)
- Use kebab-case branch names
- Keep one focused scope per PR (feature/fix/refactor)
- Use conventional commits

Suggested naming pattern:
- feat/<phase-name>
- fix/<phase-name>
- docs/<phase-name>
